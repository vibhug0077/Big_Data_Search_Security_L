Search API
- GET /products/_search

curl "localhost:9200/products/_search?pretty"

Step-11: Match all products with name containing "Apple"
curl -X GET "localhost:9200/products/_search?pretty" -H 'Content-Type: application/json' -d'
{
    "query": {
        "match": {
            "name": "Apple"
        }
    }
}
'

Step-12: Match all products containing "Apple" anywhere in the document
curl -X GET "localhost:9200/products/_search?pretty" -H 'Content-Type: application/json' -d'
{
    "query": {
        "multi_match": {
            "query": "Apple",
            "fields": ["*"]
        }
    }
}
'


Step-13: Match with the phrase "Apple IPhone 17"
curl -X GET "localhost:9200/products/_search?pretty" -H 'Content-Type: application/json' -d'
{
    "query": {
        "match_phrase": {
            "name": "Apple IPhone 17"
        }
    }
}
'
